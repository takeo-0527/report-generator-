GEMINI 長文生成ツール ・ CLIENT-ONLY

画像資料から、
一冊の原稿を書き起こす。

複数枚の画像資料と目標文字数を渡すと、構成案の作成から各章の執筆までを自動で行います。すべての処理はこのブラウザの中だけで完結し、サーバーには何も送信されません。

一

API設定

Google AI Studio で発行した Gemini API キーを使用します。キーはこの端末のブラウザにのみ保存されます。

保存すると次回以降このアプリを開いたときに自動で読み込まれます。
2026年8月時点の現行モデルです。古いモデル名（gemini-2.5系など）はGoogle側で新規利用停止となっています。
二

資料のアップロード

JPEG / PNG / WEBP / HEIC(HEIF) / PDF に対応。ドラッグで並び替えると、そのまま執筆時の参照順になります。

ここに画像・PDFをドラッグ＆ドロップ、またはクリックして選択
1枚〜数十枚まで対応（iPhoneのIMG_○○○○.HEIC形式も可）
三

文字数・指示

全体の目標文字数と、書いてほしい視点や体験談などを伝えます。

四

生成

構成案の作成 → 各章の執筆 → 結合、の順に自動で進みます。

進捗（原稿用紙イメージ） 0 / 0 文字
五

完成原稿

内容を確認し、必要な形式で書き出してください。

全体文字数：0 文字
